# Screenshots

This folder is intentionally empty of images.

The Power BI report in this project ships as an assembly kit, not as a `.pbix` file —
`powerbi/assembly_guide.md` is a click-path that rebuilds the report from
`powerbi/data/` in roughly 30-45 minutes. No dashboard images are included, because
publishing a picture of a report that was never built would misrepresent the work.

After assembling the report, drop your own captures here:

| File | Capture |
|---|---|
| `page1_executive_summary.png` | Page 1 with no slicer filters applied |
| `page2_logistics_prescription.png` | Page 2 with no slicer filters applied |
| `page2_filtered_example.png` | Page 2 filtered to a single city, to show slicer sync |

Capture at 1920x1080 or wider so the KPI card labels stay legible.
