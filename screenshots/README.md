# Screenshots

Captures of the HTML dashboard in `dashboard/`.

| File | Shows |
|---|---|
| `dashboard-overview-dark.png` | Overview tab, dark theme, no filters applied |
| `dashboard-overview-light.png` | Overview tab, light theme |
| `dashboard-sellers-dark.png` | Sellers tab — seller late rate, approval lag, cross-state shipping |
| `dashboard-geography-dark.png` | Geography tab — state and region performance |

Regenerate them by opening `dashboard/index.html` and capturing at 1600px wide or more, so the
KPI card labels and the sample sizes stay legible.

The Power BI report is assembled from `powerbi/` — see `powerbi/assembly_guide.md`. Add captures of
it here once built, named `powerbi-page1.png`, `powerbi-page2.png`, `powerbi-page3.png` to match the
three pages in `powerbi/dashboard_specification.md`.
